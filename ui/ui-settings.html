AI Providers

Here you can repair or extend any provider yourself — change its server address, add new model names, or create a completely new provider — without waiting for an extension update. Leave a field empty to keep the built-in value.
Advanced: custom API adapter (JSON spec)

For APIs none of the built-in formats can talk to. Describe the request/response shape as JSON: endpoint, auth, body template (placeholders $MODEL, $MESSAGES, $SYSTEM, $STREAM, $TEMPERATURE, $MAX_TOKENS), and where the answer text lives (textPath / ssePath). When a valid spec is saved it replaces the built-in format for this provider.

Custom Prompts

Warning: The extension depends on strict JSON output from the AI. Changing prompts can break guide generation, flashcards, quizzes, and exam questions.
